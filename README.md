# Meridian Terminal

An open-source charting and market analysis platform inspired by TradingView.

</div>

---

## Features

- Interactive candlestick charts
- Multiple timeframes
- Customizable chart layouts
- Drawing tools and technical analysis
- Technical indicators
- Market watchlist
- Demo market data

## Getting Started

```bash
git clone https://github.com/wkg2673/meridian-terminal.git
cd meridian-terminal
```

Start the dev server using `npm dev run`.
